# Pravin R — 3D React Portfolio

A responsive portfolio starter built with React, Vite, Three.js, React Three Fiber, Drei, Framer Motion and Lucide icons.

## Run locally

1. Install Node.js (LTS).
2. Extract the ZIP and open the project folder in VS Code.
3. Open the terminal in that folder and run:

```bash
npm install
npm run dev
```

4. Open the local URL Vite prints (usually `http://localhost:5173`).

## Customize before publishing

The portfolio retains Pravin's profile, project links, education and contact details. Update those details in `src/App.jsx` if they change. The JobZen job portal includes a link to its live deployment in the Featured Projects section.

The resume is available at `/Pravin_R_Frontend_Developer.pdf`. The contact form opens the visitor's email app with a prefilled message; it does not send or store messages on a server. Connect a form service or your own API if server-side submissions are needed.

Project preview images are loaded from Unsplash and require an internet connection. Replace with local images if desired.

## Production build

```bash
npm run build
npm run preview
```
