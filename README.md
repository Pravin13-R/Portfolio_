# Pravin R — React Frontend Developer

I built this portfolio to show my frontend projects, skills, and experience as I move from mechanical engineering into software development.

## Why I used 3D

I use a small Three.js scene in the hero to add depth while keeping the page focused on my work. The scene pauses when it is offscreen, responds to reduced-motion preferences, and does not capture touch gestures, so the page can scroll normally on mobile.

## Tech stack

- React and Vite
- Three.js, React Three Fiber, and Drei
- Framer Motion
- Lucide and Simple Icons
- Netlify Forms for contact submissions

## Run locally

Install Node.js, then run:

```bash
npm install
npm run dev
```

Vite prints the local development URL in the terminal.

To create and preview a production build:

```bash
npm run build
npm run preview
```

## Netlify Forms

The contact form uses Netlify's static form detection and URL-encoded submission. Deploy the site to Netlify to receive submissions; the form includes a honeypot field.

## Publishing

`dist/` is ignored because it is generated by `npm run build`. If Git is already tracking the generated directory, untrack it with:

```bash
git rm -r --cached dist
```
